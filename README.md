# SunmiFE - Sunmi Fiscal Receipt Frontend

POS application for Sunmi terminals with fiscal receipt printing.

## Version

**v2.0.0** (2026-07-15)

## Features

### Receipt Printing

- ✅ Proforma receipts
- ✅ Fiscal receipts with retry
- ✅ Native QR code support
- ✅ Logo/branding images
- ✅ Multiple styling options
- ✅ JSON-based formatting

### Technology Stack

- **Language**: Kotlin
- **Framework**: Android (API 24+)
- **Printer**: Sunmi M2, M3, M4
- **Serialization**: Gson
- **Networking**: Retrofit2 + OkHttp3
- **Async**: Coroutines
